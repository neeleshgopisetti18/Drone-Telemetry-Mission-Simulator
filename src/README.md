# Autonomous Drone Mission Control System

## Overview
This project simulates a real-time drone mission control dashboard with mission-based telemetry logic.

## Features
- Mission State Machine (Takeoff, Cruise, Surveillance, Landing)
- Real-time telemetry updates (1-second interval)
- GPS drift simulation
- Dynamic battery consumption
- Distance tracking
- Safety warning system
- Telemetry logging to file
- Aerospace-style UI dashboard

## Technologies
- Python 3
- Tkinter (GUI)

## How to Run
cd src
python mission_control.py

## Output
- GUI Dashboard
- Telemetry Log File (telemetry_log.txt)
